🧠 HOW IT WORKS (Technical Deep Dive) 
---
```
# Step 1: Base64 encoded API endpoint (stealth)
API_BASE = "aHR0cHM6Ly9lbnRoZW0tcGFpZC1hcGkudmVyY2VsLmFwcC9hcGk..."

# Step 2: Decode at runtime
api_url = base64.b64decode(API_BASE).decode('utf-8')

# Step 3: Append target number
url = api_url + str(mobile_number)

# Step 4: HTTP GET request
response = requests.get(url, timeout=15)

# Step 5: Parse JSON
data = response.json()

# Step 6: Colorize output
for key, value in data.items():
    print(f"\033[96m{key}\033[0m: \033[92m{value}\033[0m")
```
